# 反模式清单（违反任一条 = 烧预算）

- **不要**提交越出物理边界的回归解——线性假设已崩塌，提了也是白烧。
- **不要**在窄盆地内做小于盆地尺度的微调——改用跨盆地最小二乘。
- **不要**在未实测敏感度的杠杆上花试算——先花 2–3 次试算测方向和比值。
- **不要**在 `escalate_at` 次不收敛后仍坚持原结构参数——切档结构参数可能重塑整个响应面。
- **不要**超过 `max_trials` 后继续盲爬山——无盆地策略的山地搜索是烧预算。
- **不要**为单个模型放宽通过阈值——同系列所有模型必须同一收敛标准，否则趋势表不可比。
- **不要**删除任何 PASS 结果的原始产物与参数文件——它们是参数↔结果的唯一链接，也是下一个模型外推的种子。
