# 盆地（响应面不连续）识别与恢复

## 定义
**盆地**：(X, Y) 空间内靶标 B 响应连续的离散区域。跨过边界时，极小步长即引发
B 误差跳变（阈值见 config `thresholds.basin_jump`）。离散介质（颗粒/键合模型）常见。

## 判据
- 参数步长 < `per_dX` 却引发 |ΔerrB| > `dErrB`（默认：每 0.01e6 跳变 > 3 个百分点）= 跨过盆地边界。
- 量化检验：`|errB(T_new) - errB(T_near)| / |X(T_new) - X(T_near)|` 折算到单位步长；
  超 1 倍阈值 = 踩界，超 1.5 倍 = 两点分属不同盆地 → 盆地恢复。
- 经验规律（可移植的定性结论）：杠杆进入低值区时盆地碎化加剧；同族模型的盆地结构会漂移，
  不能直接复用边界坐标，只能复用「存在盆地」这个事实与检测方法。

## 恢复流程（S5）
1. 标记安全盆地点（|errB| < 3%）与可用邻盆地点（3–10%，含可用线性趋势）；
2. 凑 4–6 点，X 跨度至少覆盖盆地尺度的 10 倍步长；
3. 用**最小二乘**（`scripts/regress_lstsq.py`，非精确解）拟合两靶标响应面；
4. 🔴 CHECKPOINT 3：两模型 R² ≥ `regression_r2`（默认 0.9）才可提交；不足则在中间 X 区间补 1–2 点重拟。

## 成功案例（原项目 a45_w6）
T4/T5（中应变盆）+ T8/T12（低应变盆）→ 5 点最小二乘 → emod=4.318, pb=0.977 → T14 PASS。
